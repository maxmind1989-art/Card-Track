# CardTrack

A small personal app for tracking UAE credit cards and monthly expenses in AED. It runs in Safari and installs to the iPhone Home Screen.

## Install on iPhone
1. Open the GitHub Pages link in **Safari**.
2. Tap **Share** → **Add to Home Screen**.
3. Open CardTrack from the Home Screen.

All data is stored only on the phone. Use **More → Export backup** now and then.
